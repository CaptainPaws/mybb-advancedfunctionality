- **high** — Advanced Element Theme использует собственный Canvas/RAF runtime вопреки прямому запрету контракта: `inc/plugins/advancedfunctionality/addons/advancedelementtheme/assets/element-canvas-engine.js:361-398`.

- **medium** — Контрактные ARPG helper API не найдены, полный consumer pipeline ACS не подтверждён: текущие чтения Character Sheets находятся в `inc/plugins/advancedfunctionality/addons/charactersheets/modules/render.php:393-443`, `:1807-1877`.
- **medium** — Advanced Appearance допускает raw image/background URL вопреки ограничению контракта: `inc/plugins/advancedfunctionality/addons/advancedappearance/studio.php:15`, `inc/plugins/advancedfunctionality/addons/advancedappearance/postbit_studio.php:9`.
