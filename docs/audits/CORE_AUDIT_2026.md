### Подтверждённые механизмы защиты

- **SQL:** строковые значения в условиях проходят через `$db->escape_string()` (`inc/plugins/advancedfunctionality.php:555-557`, `inc/plugins/advancedfunctionality.php:6535-6536`), идентификаторы приводятся к `int` (`inc/plugins/advancedfunctionality.php:573-580`, `inc/plugins/advancedfunctionality.php:4020-4037`), CSS перед записью через query builder экранируется (`inc/plugins/advancedfunctionality.php:4048-4052`, `inc/plugins/advancedfunctionality.php:4814-4819`). SQL с `LIKE` в ядре не найдено.
- **XSS:** переменные, подставляемые в строку шаблона перед `eval`, экранируют обратную косую черту, двойные кавычки и переводы строк (`inc/plugins/advancedfunctionality.php:257-275`); заголовок страницы экранируется (`inc/plugins/advancedfunctionality.php:283-289`). Пользовательские и считанные из БД значения в ACP выводятся через `htmlspecialchars_uni()` (`inc/plugins/advancedfunctionality.php:812-836`, `inc/plugins/advancedfunctionality.php:894-927`). Небезопасного прямого вывода пользовательских данных в eval-шаблоны ядра не найдено.
- **CSRF:** действия включения/выключения аддонов и все действия со stylesheet требуют `verify_post_check()` (`inc/plugins/advancedfunctionality.php:362-375`); формы содержат `my_post_key` (`inc/plugins/advancedfunctionality.php:505-510`, `inc/plugins/advancedfunctionality.php:1045-1052`). Маршрут состояния аватара также проверяет post key (`inc/plugins/advancedfunctionality/avatar.php:65-71`).
- **Права ACP:** регистрируется разрешение `index` для модуля (`inc/plugins/advancedfunctionality.php:1616-1624`), все разделы и действия проходят через общий прокси этого модуля (`inc/plugins/advancedfunctionality.php:1629-1637`, `inc/plugins/advancedfunctionality/admin/router.php:6-8`). Отдельных admin-точек входа вне модуля в ядре не найдено.
- **Загрузка файлов:** принимается только реальный multipart-файл (`is_uploaded_file`), тип определяется через `getimagesize`, обрабатывается только WebP (`inc/plugins/advancedfunctionality/avatar.php:108-120`); проверяются post key и права пользователя (`inc/plugins/advancedfunctionality/avatar.php:116-119`), размер, размеры изображения и лимит памяти (`inc/plugins/advancedfunctionality/avatar.php:120-138`); преобразованный файл передаётся штатному обработчику аватаров MyBB (`inc/plugins/advancedfunctionality/avatar.php:151-155`). Иной собственной загрузки файлов в ядре не найдено.

### Вся подтверждённая работа ядра на каждый запрос

- **На `global_start`:** загрузка языка ядра (`inc/plugins/advancedfunctionality.php:2295-2299`); однократная за запрос проверка legacy-настройки аватаров, полный discovery, проверка legacy ID, синхронизация и загрузка языков, подключение и `init` всех включённых аддонов (`inc/plugins/advancedfunctionality.php:2322-2382`). SQL-запросы в обычном пути этого bootstrap не найдены; миграция avatar и записи settings выполняются только при включённой legacy-настройке (`inc/plugins/advancedfunctionality.php:2420-2455`).
- **На каждой frontend HTML-странице через `pre_output_page`:** повторный discovery и вызов pre-output обработчиков; runtime-проверки templates/CSS; фильтрация очереди CSS; сборка и вставка ассетов; SQL-проверки theme registry/stylesheets и наследования тем; финальные проходы по link/script/charset (`inc/plugins/advancedfunctionality.php:2459-2478`, `inc/plugins/advancedfunctionality.php:2625-2701`). Для `usercp.php`/`misc.php` тот же набор может выполняться из shutdown после полного буферирования ответа (`inc/plugins/advancedfunctionality.php:2483-2507`, `inc/plugins/advancedfunctionality.php:2580-2618`).
- **На `xmlhttp.php`:** glob/include всех манифестов и bootstrap всех включённых аддонов независимо от action (`inc/plugins/advancedfunctionality.php:2510-2577`); для AF-action дополнительные discovery и диспетчеризация (`inc/plugins/advancedfunctionality/gateway_stub.php:50-85`, `inc/plugins/advancedfunctionality.php:6247-6277`). Runtime-sync templates и pre-output HTML-фильтры для `xmlhttp.php` пропускаются (`inc/plugins/advancedfunctionality.php:6397-6400`, `inc/plugins/advancedfunctionality.php:2960-2997`).
- **Постоянных SQL-запросов непосредственно в `global_start` не найдено.** Основная подтверждённая БД-нагрузка ядра находится в pre-output/delivery CSS; запросы в циклах per-post в самом ядре не найдены — postbit-мост лишь вызывает уже загруженный provider (`inc/plugins/advancedfunctionality.php:2410-2417`).
