# APStudio: аватар Sidebar после Quick Edit

Причина: `xmlhttp.php?action=edit_post&do=update_post` сохраняет сообщение и маску, затем штатный MyBB Quick Edit заменяет только содержимое сообщения. `post-masks.js` запрашивает `api=mask`, операция `runtime`, чтобы обновить CSS, эффекты и два аватара. В этом отдельном запросе не выполняются postbit-хуки APF/ATF и отсутствует кэш авторов ATF. Раньше query-free рендереру дополнительного аватара передавались лишь UID и имя. Для унаследованного аватара он возвращал пустую строку, которой клиент заменял содержимое `.atf-post__secondary-avatar`.

Runtime теперь получает нормализованный URL через `af_apf_get_secondary_avatar()` — тот же источник Profile Fields, который используется при первоначальном postbit. Приоритет сохраняется: явный аватар маски, изображение snapshot/активного пресета, исходный аватар. Если дополнительного аватара действительно нет, его область остаётся пустой.

Клиент обновляет только содержимое двух контейнеров аватаров и только при изменении нормализованной разметки. Сам сайдбар, имя, поля, элементы управления и неизменившиеся изображения сохраняют свои DOM-узлы и обработчики. Полной перезагрузки или повторной сборки сайдбара нет. Контракт сохранения маски не изменён.

При проверке полного диалога исправлена проверка подключения Gallery: URL скрипта внутри lazy-конфигурации AdvancedEditor больше не считается фактическим `<script src>`. На странице с явным потребителем Gallery (диалогом маски) подключается один runtime; ранний выход для страниц только с редактором сохраняется.

Проверки:

- `tests/appearance_mask_avatar_regression.php`: отдельный запрос без кэша postbit, унаследованный APF-аватар, основной аватар, приоритет явных аватаров/snapshot, отсутствие дополнительного аватара. На исходной версии воспроизводит ошибку `Fresh AJAX lost inherited APF avatar`.
- `tests/appearance_post_masks_integration.php`: сохранение/сброс, snapshot, владение, CSRF и права; изолированная база `appearance_test`.
- `tests/appearance_post_masks_browser.cjs`: штатный MyBB Quick Edit, смена и сброс маски, унаследованный аватар после сброса и следующего редактирования текста, сохранность DOM-узлов и обработчика сайдбара, обычные формы редактирования/публикации.
