# Конструктор содержимого подписи

Страница `usercp.php?action=editsig` использует четыре композиции: **Минимализм**, **Цитата**, **Карточка**, **Галерея**. Две колонки содержат поля, выбор композиции, общий серверный предпросмотр и переход в APStudio. Доступны заголовок, подзаголовок, многострочный текст, статус, фон, три изображения и шесть упорядочиваемых ссылок. Смена композиции сохраняет неиспользуемые поля.

## Хранение и переход

- Таблица AF `af_apui_signature_builder` связана с `users.uid`: `draft_json`, `published_json`, `published_hash`, `legacy_backup`, `updated_at`.
- «Сохранить шаблон» сохраняет один текущий черновик той же модели без публикации. Отдельного каталога именованных шаблонов нет.
- «Обновить подпись» формирует переносимый BBCode в стандартное `users.signature`. Стандартные `UserDataHandler::verify_signature()`, CSRF, ограничения групп, длины и количества изображений и переключатель подписей в старых сообщениях остаются в цепочке сохранения MyBB.
- Структурированная публикация включается только после успешной записи идентичного BBCode. SHA-256 связывает её с исходным полем: внешнее изменение стандартной подписи отключает устаревшую композицию.
- Открытие страницы не записывает данные. Для замены старой подписи требуется флажок подтверждения; первый исходник сохраняется в `legacy_backup` и доступен для копирования на странице. Произвольный старый BBCode/HTML автоматически не конвертируется.
- Ошибки сохраняют введённую модель. Таблица не удаляется при деинсталляции, чтобы не терять исходники и черновики.

## Интеграции и безопасность

Публичная подпись и живой предпросмотр используют `af_apui_sig_render()`. Предпросмотр открывает существующую готическую рамку ATF и применяет действующий пресет AdvancedAppearance, включая маску поверх фонового изображения содержимого. На публичной странице подпись остаётся свёрнутой; собственные ограничения видимости MyBB сохраняются.

APStudio ведёт к конструктору содержимого; обратная ссылка открывает раздел оформления подписи текущего пресета. Цвета, шрифты и декоративные настройки в UserCP отсутствуют. AdvancedEditor пропускает скрытое совместимое поле конструктора; остальные формы редактора продолжают работать как прежде.

Изображения загружаются через существующий Gallery Picker и его права/лимиты. Допускаются собственные одобренные локальные JPG/PNG/WebP/GIF; используется оригинальный файл, поэтому GIF сохраняет анимацию. URL изображений должны иметь расширение разрешённого формата и принадлежать текущему origin либо разрешённому Gallery домену. SVG запрещён. Ссылки допускают только HTTP(S). Текст экранируется, пользовательский HTML/CSS не интерпретируется.

Фон в переносимом BBCode представлен обычным изображением. Он учитывается в стандартном лимите изображений вместе с используемыми слотами. При отключении AF сохраняется читаемый BBCode, однако композиция и фон становятся обычным последовательным содержимым.

## Установка и границы проверки

После загрузки файлов обновить/реактивировать затронутые аддоны через ACP AdvancedFunctionality, чтобы создать таблицу, добавить четыре конфигурируемых лимита полей и синхронизировать theme stylesheets. Версии: AdvancedProfileUI 1.2.0, ATF 0.31.1, AdvancedAppearance 1.6.2, AdvancedEditor 1.1.1. При отсутствии таблицы сохранение выдаёт сообщение об обновлении; посещение страницы не запускает миграцию схемы.

Синтаксис изменённых PHP проверен на PHP 8.5.11, JS — Node. Короткие регрессионные проверки покрывают экранирование, права/CSRF, ссылки/изображения, переход со старой подписи, черновик, границы нативного сохранения, восстановление модели и общий рендерер. Проверки хранения используют модель MyBB/БД в памяти; реальные HTTP/SQL и визуальная проверка на warprift.ru не выполнялись. Миниатюры шаблонов схематические; художественные изображения из макета не входят в поставку.
