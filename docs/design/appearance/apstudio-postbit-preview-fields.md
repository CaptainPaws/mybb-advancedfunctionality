# APStudio: поля и иконки предпросмотра постбита

Предпросмотр продолжает использовать `adaptivethemeframework/templates/postbit_classic.html`, компоновку APUI и ATF, источники основного/дополнительного аватаров и опубликованную подпись. Убраны жёстко заданные «Участник», звёзды, «Звание: Искатель» и текстовая кнопка профиля.

Значения дополнительных полей читаются из MyBB `userfields` по UID владельца. APF предоставляет read-only адаптер `postbit-fields.php`: определения из кэша `profilefields`, только `postbit=1`, штатный `postParser` с настройками каждого поля и штатные `postbit_profilefield*` templates. Затем APUI выполняет существующее извлечение/форматирование полей. Вне APStudio поведение нативного `build_postbit()` не меняется.

Для каждого существующего поля добавлена зона `profile_field_<fid>` с селектором `.af-apf-postbit-field--fid<fid>`, а также общая зона полей и зона статуса. Они используют существующие валидатор, CSS-компилятор и хранение компонентов пресета. Переименование поля не меняет его ID. Пустые поля получают только в предпросмотре подпись «не заполнено»; значения пользователя не записываются. Поля без флага postbit не показываются и не становятся зонами.

Кнопки профиля формируются штатным ATF `post_context` / `iconize_post_control` с tooltip и Font Awesome. Нативные дополнительные controls используют MyBB templates и разрешения. Владельцу не показывается отправка ЛС самому себе. Локальный vendor CSS Font Awesome подключается на исходном пути, чтобы относительные ссылки на webfonts не ломались. Статистика репутации MyBB не отключается.

Проверки: `appearance_studio_integration.php` (данные, пустые/скрытые поля, стили по ID, парсер, отсутствие записей в профиль), `appearance_preview_fields_browser.cjs` (клик, dropdown, цвет, черновик, загрузка font), существующие проверки настроек постбита, выбора зон и Quick Edit масок. PHP/SQL проверки используют только изолированную `appearance_test` / `aa_test_` базу.

ЛЗ (`fid4`, существующая зона ATF) по умолчанию имеет чёрный фон с непрозрачностью 45%, скругление 4 px и внутренний отступ 5 px. Это правило действует и без пользовательского пресета. В индивидуальных зонах дополнительных полей доступны цвет/прозрачность фона, скругление и отступ. APStudio показывает фактические defaults ЛЗ; отдельное изменение прозрачности наследует чёрный цвет, явный отступ 0 сохраняется. Сброс возвращает стандартный вид. Другие поля не получают фон автоматически.
