# APStudio: фоновые слои и подпись

Реализовано для MyBB 1.8.40 / PHP 8.5. Установка на warprift.ru и полная визуальная проверка выполняются отдельно от публикации исходного кода.

## Диагностика затенения

В исходном коде фоны собирались двумя компиляторами AdvancedAppearance, а ATF отдельно собирал собственные фоновые слои. Общий компилятор знал о legacy darkening, но не overlay_*, адаптер напрямую заменял background-image вместо управления переменными слоя ATF. Маска добавлялась ниже дымки. Подтверждён отдельный дефект: overlay_mode=none без своего изображения не генерировал отключение маски, поэтому продолжала действовать маска ATF/APUI. Слой тела сообщения вообще не был доступен адаптеру; его фиксированный filter также влиял бы на добавленную туда светлую маску.

Эти несогласованности устранены общим контрактом переменных. Точную причину сообщения «максимальное затенение не видно» на рабочем сайте без его DOM, вычисленных стилей и активного пресета подтвердить нельзя. Локальные проверки подтверждают исправленный путь от сериализованного пресета до реального изображения и пикселей маски, но не подменяют диагностику конкретного установленного сайта.

## Реализация

- Три независимые области: topbar, sidebar, message_background. AdvancedAppearance задаёт --aa-<область>-image/mask/haze/gradient/color/size/position/repeat, ATF рисует фон. Общий компилятор больше не пишет конкурирующий background-image этих областей.
- Порядок сверху вниз: тональная маска, дымка, дополнительный градиент, изображение. Размер/повторение маски отделены от размера/повторения картинки.
- none явно отключает дополнительную маску; отсутствие режима наследует ATF/APUI. darken/lighten без своего цвета используют чёрный/белый. Альфа каждого конца = интенсивность × значение конца градиента.
- Сайдбар получает собственные haze_*; фон остаётся на sidebar-inner. Sticky-родители, их transform/overflow и геометрия не менялись.
- Фон сообщения использует существующий layout::before. Без пользовательских параметров сохраняются исходные текстура, размеры, повтор и фильтр темы. При кастомизации отключается фильтр только этого декоративного псевдоэлемента, чтобы не искажать выбранные цвета и осветление. Текст и содержимое не фильтруются.
- Gallery Picker, проверка URL, выдача исходных GIF и проверка media ID переиспользованы. Нового загрузчика нет. Удаление изображения и возврат исходного остаются разными действиями.
- Названия в UI изменены на «Затенение». overlay_* и формат старых значений сохранены; legacy darkening читается. Сброс группы/области удаляет только её поля; новых миграций БД нет.
- Для заголовка, подзаголовка, цитаты и кнопок подписи добавлены самостоятельные компоненты. Типографика включает семейство, размер, вес, начертание, выравнивание, интервалы и свечение. Цитата дополнительно получает цвет/альфу фона, отступы и цвет разделителя; её селектор ограничен шаблоном quote.
- Кнопки получают цвета текста/фона/границы, состояния hover/focus, шрифт и свечение. По умолчанию цвет и граница берутся из акцента пресета. Отдельные настройки имеют приоритет перед общими цветами ссылок подписи.
- Использован реестр шрифтов AdvancedEditor и существующая доставка font-face. Один компилятор применяется в постбите, preview и профиле. UserCP, содержимое подписей и готические рамки не изменялись.

## Изменённые файлы

Относительно inc/plugins/advancedfunctionality/addons/:

1. advancedappearance/postbit_studio.php — схема, переменные фоновых слоёв, компоненты подписи и профильный scope.
2. advancedappearance/studio.php — разделение ответственности общего и постбит-компиляторов.
3. advancedappearance/assets/studio.js — подписи контролов, группы и цвет маски по режиму.
4. adaptivethemeframework/assets/surfaces/postbit.css — чтение переменных на действующих фоновых слоях.
5. advancedsignaturebuilder/assets/signature-view.css — акцент кнопок по умолчанию.

Также добавлены tests/appearance_background_layers_regression.php, tests/appearance_background_layers_browser.cjs и этот отчёт.

## Проверки

- PHP 8.5: синтаксис обоих изменённых PHP-файлов, новая регрессия (включает appearance_postbit_settings_regression.php), signature_builder_integration_regression.php.
- Node: синтаксис studio.js и браузерного сценария.
- Chromium: CSS, созданный реальным PHP-компилятором, применяется к topbar, sidebar-inner и layout::before; проверены изображение, дымка, маска, масштаб и положение. Проверка пикселей подтверждает чёрную/белую маски при 100% и равенство интенсивности 0 режиму none. Прозрачность контейнеров остаётся 1.
- Проверены сериализация новых полей, старые пресеты, независимые переменные, наследование и профильный scope подписи; git diff --check.

Для браузерного сценария сначала запустить PHP-регрессию с AA_TEST_CSS_OUTPUT=work/compiled.css, затем node tests/appearance_background_layers_browser.cjs. Playwright использует AA_CHROMIUM, системный /usr/bin/chromium либо свою установленную сборку. Сценарий локальный, сетевые изображения блокируются.

Полная визуальная проверка сайта остаётся заказчику по критериям ТЗ. При установке заменить все пять исходных файлов совместно и обновить кэш CSS/ресурсов применяемым на форуме способом.
