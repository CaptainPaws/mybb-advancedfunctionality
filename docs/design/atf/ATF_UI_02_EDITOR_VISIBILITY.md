# ATF-UI-02 — Видимость редактора структурированной формы

AdvancedThreadFields скрывал textarea или её табличную строку после запуска JS. В адаптивных формах `newthread.php` и `editpost.php` содержимое редактора находится внутри `.atf-compose__field--editor`, поэтому оставались заголовок и отступы.

Для структурированной формы AdvancedThreadFields отмечает основной `textarea[name="message"]` в HTML-ответе. Правило в `<head>` скрывает целиком адаптивную оболочку или ближайшую табличную строку до запуска JS. Скрипт формы сохраняет резервный путь для браузеров без `:has()`. Существующий метатег режима сохранён для совместимости с модулем предпросмотра AdvancedEditor.

В хуках окончания сборки формы убирается запуск встроенного SCEditor для основного поля. Атрибут `data-af-ae-skip="1"` исключает это поле из первоначального и динамического запуска AdvancedEditor. BBCode-поля самой структурированной формы продолжают обслуживаться AdvancedEditor. Поле `message` остаётся доступным для отправки. MyBB сохраняет штатную валидацию и серверную подстановку невидимого текста через `af_atf_force_min_message_if_needed()`.

В `editpost.php` используется существующая проверка первого сообщения. Обычные темы, ответы и Quick Reply продолжают пользоваться соответствующими редакторами. Предпросмотр и повторный показ после ошибок используют существующий сбор значений ATF из POST.

## Ручная приёмка

- Открыть создание темы на адаптивном и стандартном шаблонах MyBB. Проверить отсутствие заголовка, textarea, панели и пустого пространства на месте редактора. Проверить BBCode-поля ATF с включённым и выключенным AdvancedEditor.
- Заполнить поля, открыть предпросмотр, затем отправить форму с пропущенным обязательным полем. Проверить, что введённые значения остаются. Исправить ошибку и отправить форму.
- Сравнить редактирование первого поста и ответа в одной ATF-теме. Проверить обычную тему, обычный ответ и Quick Reply.

`git diff --check` и `node --check` изменённого JS прошли. PHP CLI недоступен. Автоматические тесты не создавались и не запускались.
