# ATF-UI-01D — Метапанель и счётчик первого структурированного сообщения

## Метапанель

Компактный первый postbit использует одну строку `atf-post__meta-line atf-thread__author-meta` внутри карточки темы. Слева находятся аватар, имя, inline moderation, ссылка `#1`, дата и счётчик. Справа находится штатный `post.actions`. На мобильной ширине действия переносятся на следующую строку в пределах той же панели.

Панель получает разрешённые кнопки из существующего слота MyBB/ATF. Ссылки, токены и серверные проверки прав остаются штатными. Служебная разметка с ID первого сообщения по-прежнему позволяет перейти по `#1` и обслуживает нативные действия. Подпись автора из компактной панели удалена вместе с элементом раскрытия. Полноценные postbit продолжают использовать собственные метаданные и подписи.

## Счётчик символов

AdvancedThreadFields передаёт фрагменты значений, которые его штатный рендерер включил в карточку. Сервис считает отображаемый текст, включая заголовок из поля, описание, подписи выбранных вариантов и имена участников из ссылок. Пустые и скрытые поля пропускаются при формировании карточки. Атрибуты, адреса изображений, декоративные элементы, служебные подписи и закрытые технические параметры исключаются при извлечении текста. Видимый текст ссылки учитывается.

Текст извлекается из фрагментов значений до подсчёта. Пробелы, в том числе между полями и абзацами, сводятся к одному пробелу. Счётчик считает кодовые точки UTF-8, поэтому буква кириллицы учитывается как один символ.

Счётчик скрывается, если текста нет, обработка фрагмента невозможна или изменённый шаблон не выводит один из заполненных блоков в ожидаемом виде. Для фрагментов с HTML используется PHP DOM. Без этого расширения обрабатываются только темы со значениями без разметки. Подсчёт выполняется на сервере и не вычисляет видимость по произвольным правилам CSS с сервера форума.
