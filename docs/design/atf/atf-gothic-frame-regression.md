# ATF 0.32.3: восстановление готических рамок

Причина установлена по публичному HTML `https://warprift.ru/showthread.php?tid=14&pid=714` и CSS активной темы (17.10.2026). Оба файла `cache/themes/theme2/postbit.min.css?t=1792263765` и `signature.min.css?t=1792263765` отвечали HTTP 200. Разметка постбитов и декоративных элементов присутствовала.

В 41a34cb общие SVG/переменные/правила рамок переместились в signature.css под селекторы `body.atf-active :is(.atf-post, .atf-signature-surface)`. Минификатор MyBB 1.8.40 удаляет пробелы вокруг двоеточия: в CSS темы получился `body.atf-active:is(...)`. Такой селектор требует класс постбита на самом body и не выбирает постбит. Поэтому одновременно исчезли внешняя рамка, рамки аватаров, камни и оформление разделителей. Наличие CSS-файла не означало применение его правил.

Общий декор возвращён в postbit.css без изменения SVG, размеров и геометрии. Вместо descendant `:is()` используются явные списки селекторов, устойчивые к штатной минификации. В signature.css остаются раскрытие подписи и её адаптации. postbit.css прикреплён также к member.php для общего самостоятельного контейнера профиля. Имена stylesheet и существующая система Theme/File сохранены; новых загрузчиков нет.

Отдельно подтверждён HTTP 404:
`https://warprift.ru/inc/plugins/advancedfunctionality/addons/adaptivethemeframework/assets/adaptivethemeframework.signature.js?v=0.32.2`.
Файл есть в Git, но отсутствовал на сервере. Это отдельная проблема развёртывания, не причина исчезновения CSS-рамок. Запрос исключён: небольшое улучшение ARIA/фокуса для нативного details перенесено в уже доставляемый presentation-preferences.js. Старый файл оставлен совместимым вызовом общей функции. Повторной регистрации обработчиков нет; учитывается ранняя загрузка в head.

Изменены в ATF: manifest.php, adaptivethemeframework.php, assets/surfaces/postbit.css, assets/surfaces/signature.css, assets/presentation-preferences.js, assets/adaptivethemeframework.signature.js. Дополнены tests/signature_runtime_regression.cjs и tests/atf_gothic_css_regression.php. AdvancedAppearance и модель конструктора не менялись: проверки компилятора подтвердили изоляцию пресета владельца и отсутствие изменения геометрии постбита.

Проверены PHP/JS-синтаксис, реальное преобразование минификатора MyBB, уникальность общих определений, неизменность SVG, регистрации post/profile, существующие тесты Theme/File доставки ASB, общий рендерер трёх контекстов, AA scope и runtime раскрытия. Браузерная визуальная проверка работающего MyBB после развёртывания не выполнялась.

После загрузки файлов выполнить штатное обновление ATF до 0.32.3 и синхронизацию stylesheet активной темы через AF. В Theme-режиме нужно пересоздать актуальный кэш обоих stylesheet; одного обновления файлов недостаточно. Сохранить выбранный Theme/File режим. Если stylesheet помечен системой как вручную изменённый, сравнить изменения и применить исправленные селекторы/перенос через штатные средства, не перезаписывая пользовательские правки принудительно. На сайте проверить рамки обоих аватаров и постбита, акценты, разделители, подпись в посте и профиле, отсутствие старого запроса signature.js и ошибок загрузки.
