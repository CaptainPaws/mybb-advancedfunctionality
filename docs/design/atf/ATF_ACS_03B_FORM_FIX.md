# ATF-ACS-03B — Выбор режима и компоновка темы

## Почему переключатель отсутствовал

В `editpost.php` первый непройденный guard был структурным. ACS подключал `AtfThreadCreation.php` только для `newthread.php` и `showthread.php`, а ATF вообще не вызывал `af_atf_acs_mode_input()` при редактировании. Добавлены подключение на маршруте редактирования и вызов после native-проверки первого сообщения.

В `newthread.php` исходники подтверждают два немых отказа после успешной проверки Group. `table_exists(af_atf_acs_thread_intents)` возвращал false, если после загрузки файлов аддон ещё не проходил установку или активацию. Кроме того, `canCreate()` опирается на разрешение ACP только внутри ACP. В публичной форме сотруднику без членства в группе мастеров ACS возвращался false, даже при административных правах или статусе модератора. Какой guard первым сработал в конкретном запросе warprift.ru, невозможно установить без конфигурации и состояния установленного форума.

Кэш групп прежнего формата пересобирается при отсутствии `acs_enabled`. Сохранение разрешающей Group обеспечивает штатное хранилище намерений. В явно разрешённом форуме интерфейс показывает причину отказа в порядке реальных проверок. Порядок включает состояние ACS, таблицу намерений для создания темы, доступность обработчика, native-права, право `canCreate()` и готовность схемы ACS. Значение All по-прежнему не выдаёт разрешения. Для публичной формы администраторы и модераторы используют существующий список групп мастеров ACS.

## Форма

Шаблоны Adaptive Theme Framework владеют секциями основных параметров, полей и дополнительных настроек. `AF_COMPOSE_PRESET` и `AF_COMPOSE_EPISODE` находятся после строки темы. Точка `AF_COMPOSE_FIELDS` находится в отдельной секции перед основным редактором. AdvancedAppearance выводит тот же список разрешённых пресетов в блочном формате. В стандартных табличных шаблонах сохранены строки MyBB.

Редактор и поля ATF используют прежние контракты. Сетка переносит колонки на узком экране, а многострочные поля и BBCode занимают полную ширину. Элементы используют цвета, высоты и focus-состояния темы. Поля персонажей сохраняют группы, подсказки, отметки обязательности и динамические зависимости. Для установок со старым шаблоном ATF предусмотрено размещение перед оболочкой редактора. Полный порядок секций появляется после применения актуальных шаблонов через штатный lifecycle темы.

## Сохранение

Создание темы использует механизм #1095, включая ключ формы, подтверждение TID и прежний ключ операции ACS. При редактировании боевой режим проверяется на `editpost_do_editpost_start`, а команда выполняется только в `editpost_do_editpost_end` после сохранения. Предпросмотр и ошибки сохраняют выбор из POST. Для редактирования существующего TID используется тот же ключ ACS и проверка отсутствия второй сессии под блокировкой. После сбоя изменения поста сохраняются, продолжить можно в GM-мастере темы.

В теме с существующей сессией отображаются боевой режим, доступный по правам статус столкновения и ссылка на мастер для GM. Закрытие и архивирование остаются операциями ACS. Форма не меняет существующую сессию или историю.

## Проверки

`git diff --check` и `node --check` изменённого JS прошли. PHP CLI отсутствует. Автоматические тесты не создавались и не запускались.
