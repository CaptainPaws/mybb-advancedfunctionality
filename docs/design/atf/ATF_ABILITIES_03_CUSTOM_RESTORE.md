# ATF-ABILITIES-03 — Собственные способности в анкете ARPG

PR #1123 добавлял `hidden` к кнопке `.af-atf-abilities-add` в ветке `character_abilities` функции `af_atf_build_input_html()`. В `af_atf_dh_validate()` тот же PR отклонял все новые и изменённые собственные способности ARPG. Оба ограничения сняты. «Создать свою» открывает существующий редактор, а «Выбрать из KB» открывает каталог.

ATF сохраняет смешанный массив в пределах восьми строк. Собственный редактор работает со своими строками. Карточки каталога сохраняют `ability_source`, `ability_kb_key` и подтверждённую версию. Сервер повторно проверяет выбор каталога и сохраняет слот прежней закреплённой записи при удалении соседней строки. Синхронизация ATF с KB сравнивает только непустые ключи каталога. Независимая способность без ключа больше не вытесняет другие собственные записи. Существующие строки и закреплённые снимки сохраняются без миграции.

## Сохранение и готовность

ATF проверяет структуру новых и изменённых строк, числовые значения, введённые ключи по действующим вариантам редактора KB и правила явно указанной стихии. Пустой параметр можно оставить в черновике. Например, собственная способность с названием сохраняется даже без цели, эффекта или единицы времени. При открытии сохранённой формы «Требует настройки для ACS» перечисляет причины, найденные нормализатором. Для правок в текущей форме этот список обновляется после сохранения и повторного открытия. В DnD применяется прежняя ветка проверки.

При подготовке снимка отсутствие цели, эффектов или количества заявленного ресурса у отдельной собственной записи остаётся блокировкой. Действующие проверки формул, единиц времени, ресурсов и версий выполняются отдельным путём ACS. Выбор боевых действий продолжает использовать действующий контракт закреплённых определений KB. Эта работа возвращает авторинг и сохранение, сохраняя действующие правила исполнения.

## Ручная приёмка

1. В ARPG открыть создание и редактирование анкеты. Проверить обе кнопки и сохранение заполненных полей собственной способности после повторного открытия.
2. Сохранить смешанный набор, удалить сначала одну собственную, затем одну готовую способность. Проверить остальные строки, слоты, порядок и отпечатки ссылок после синхронизации.
3. Сохранить собственную способность с одним названием. Снова открыть редактирование и проверить причины статуса «Требует настройки для ACS». Проверить отказ при подготовке снимка для этой способности.
4. Ввести некорректное значение или ключ. Проверить, что отказ называет способность и поле. Проверить общий предел в восемь записей.
5. Повторить сохранение обычной анкеты DnD и сверить поведение.

Выполнены точечные `php -l`, `node --check` и `git diff --check`. Ручная приёмка выполняется владельцем проекта на форуме.
