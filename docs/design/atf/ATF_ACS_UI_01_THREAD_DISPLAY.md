# ATF-ACS-UI-01 — Поля темы и автор

## Вывод в теме

Верхняя карточка `showthread` использует существующий слот `thread.atf_fields` и общий рендерер AdvancedThreadFields. MyBB собирает postbit до `showthread_end`, поэтому первый пост сначала получает резервный блок. После сборки слота Adaptive Theme Framework сверяет разметку с тем же блоком и проверяет наличие точки вывода в выбранном шаблоне. При совпадении из списка сообщений удаляется только отмеченный резервный фрагмент. Если слот недоступен или Adaptive Theme Framework отключён, поля остаются в первом сообщении.

Видимый первый пост со служебным заполнителем и без вложений сворачивается до компактного блока штатных элементов. К исходному сообщению по-прежнему ведёт MyBB-ссылка с якорем. Сохраняются идентификаторы, редактирование, модерация, подписи и слоты дополнений. Самостоятельный текст, медиа и вложения оставляют обычный postbit. Пагинация и последующие ответы остаются в штатном потоке MyBB.

Внизу верхней карточки выводятся имя автора темы, ссылка на профиль, маленький аватар, дата создания и ссылка на первый пост. Автор берётся из записи темы. Аватар использует имеющийся компонент AdvancedAppearance, когда тот предоставил персональную разметку, и штатное изображение MyBB в остальных случаях. Строка переносится на узком экране.

Wiki-шаблон выводит заголовок только при наличии значения `character_name`. Пустая шапка опускается. Существующий значок элемента сохраняется, если он задан полями.

## Ручная приёмка

1. Открыть анкету с `character_name` и эпизод без него. Сравнить заголовки и убедиться, что поля видны один раз.
2. Сравнить тему со служебным первым постом, тему с литературным текстом и тему с вложением или встроенным медиа. Проверить, что уплотняется только первый случай.
3. Проверить последующие ответы, следующую страницу, режимы postbit, профиль автора, якорь первого поста, редактирование и модерацию.
4. Проверить узкий экран и тему с выключенным Adaptive Theme Framework. При выключенном AdvancedThreadFields открыть обычную тему.
5. Если форум использует локальные переопределения шаблонов, сверить актуальный шаблон `af_atf_display_block` и точку вывода `atf_thread_fields`.
