# KB-TYPES-01 — Активность и видимость типа

В ACP → Knowledge Base → Типы и в редакторе типов KB доступны два независимых переключателя. «Тип активен» сохраняет функциональную активность. «Показывать в каталоге KB» задаёт публичную видимость. Колонка «В каталоге» в ACP показывает настройку для обычного типа и отмечает служебные типы отдельно.

## Хранение

Штатное обновление схемы KB при активации добавляет `af_kb_types.show_in_catalog`. Обычные существующие типы получают значение 1, служебные получают 0 только при создании столбца. Новые штатные служебные типы также создаются скрытыми. Повторная активация не перезаписывает этот столбец. Обновление схемы сохраняет текущую активность, названия, правила и записи `af_kb_entries`. Если администратор ранее отключил `arpg_mechanics`, его нужно вручную активировать и оставить скрытым.

## Политика чтения

- Публичная навигация, список типов, поиск и каталог способностей требуют активный видимый тип. Списки исключают служебные типы независимо от настройки и выбранного режима механики.
- Прямое чтение страниц и запросы записи по ключу или ID, чипы KB и HTTP-запросы связей проверяют права редактора либо активность и публичную видимость типа и записи. Скрытый или служебный тип нельзя прочитать через перебор ключей или ID без соответствующих прав. Публичные запросы к закрытой KB используют штатную проверку просмотра.
- Редактор может открывать служебные записи напрямую. Фильтры управления в JSON доступны через `manage=1` только при наличии прав редактирования. Публичная выдача по умолчанию не включает скрытые типы даже для редактора.
- Серверные потребители ACS, CharacterSheets, AdvancedThreadFields, AdvancedShop и реестры механик продолжают использовать прежние PHP-контракты и проверки. Публичный поиск готовых способностей использует публичный каталог, а серверная проверка ссылки в анкете сохраняет прежний контракт. ACS Testpack проверяет функциональный `active`, поэтому скрытый активный `arpg_mechanics` проходит эту проверку.
- Встроенные справочные значения правил, например 17 основных стихий, остаются частью механических реестров. Скрытие типа убирает его раздел из публичной выдачи.

## Проверки

`git diff --check` и `php -l` для изменённых PHP-файлов выполнены. Ручная приёмка на MyBB остаётся открытой. Скрыть активный `arpg_mechanics`, проверить публичный каталог и чтение по URL, ключу, ID и через связи. Отдельно проверить доступ редактора, внутренние обращения ACS и Testpack, видимый обычный тип, неактивный тип и сохранение настройки после повторной активации KB.
