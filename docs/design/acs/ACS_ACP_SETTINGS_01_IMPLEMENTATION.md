# ACS-ACP-SETTINGS-01 — Настройки и право создания сессий

## Право создания

`AF_ACS_SessionAccess::canCreate()` вызывал `administrator()`, а тот проверял `admin.view` через `afAdministrator()`. Это право ограничено `IN_ADMINCP`. Поэтому публичная форма считала администратора без группы мастеров неуполномоченным.

Для создания сессии выделена отдельная проверка. Она принимает текущую аутентифицированную учётную запись с native-допуском в ACP и подтверждённым статусом супер-администратора либо правом `advancedfunctionality.index`. На публичной странице право разрешает штатный `get_admin_permissions()` MyBB из настроенного каталога ACP. Само наличие `cancp` для предоставления права недостаточно. Явный список групп мастеров также продолжает действовать. Проверки `admin.view`, других полномочий ACP, прав на выбор другого владельца и роли внутри существующих сессий используют прежние контракты.

Выбор эпизода и POST продолжают проверять разрешение ATF Group, права MyBB на создание и просмотр тем и готовность ACS. Перед созданием сессии проверяется native-доступ к теме. Без права создания форма сообщает об отказе для текущей учётной записи.

## Форма ACP и сохранение

**ACS → Основные** позволяет редактировать группы создания сессий, роль нового участника (`observer` или `player`) и группы расширенного экспорта. Мультивыбор показывает названия существующих групп MyBB и сохранённые значения. Пустой список создания оставляет право подтверждённым администраторам. Пустой список экспорта запрещает расширенный экспорт. Выбранная группа экспорта применяется вместе с текущими требованиями GM, доступом к теме и политикой экспорта.

Диспетчер принимает сохранение из POST раздела «Основные», проверяет `admin.schema.manage` и MyBB CSRF. Сервер проверяет все ID и роль до записи. Группы сохраняются как CSV уникальных числовых ID в стабильном порядке. Одним обновлением меняются только три разрешённых значения в таблице MyBB `settings`. После записи штатный механизм AF пересобирает и перечитывает настройки, а изменение фиксируется через `log_admin_action()` без ключей или секретов.

## Восстановление настроек

Установка и обновление ACS добавляют только отсутствующие значения. Если на установленной схеме не хватает настройки, раздел «Основные» предлагает отдельный POST «Восстановить настройки ACS». Он проверяет готовность схемы без запуска миграций, добавляет отсутствующие значения и пересобирает настройки. Существующие значения сохраняются. Новый секрет курсоров генерируется только при отсутствии соответствующей записи. Простое открытие страницы записей настроек не создаёт.
