# ACS-GM-03B — Панель GM по утверждённому макету

## Интерфейс

`GmPanel.php`, `Entities.php` и `Encounters.php` формируют шапку ACS, статусные пилюли, четыре вкладки и три колонки состава. Слева находятся сворачиваемые стороны, их участники и сводка. Центр содержит карточки участников и управление стороной. Справа доступны персонажи, NPC/монстры и недавние регистрации. На узком экране колонки переходят в вертикальный режим. Прямая ссылка темы использует те же компоненты.

`thread-panel.js` открывает существующий `AFModalHost`, обновляет текущий фрагмент и сохраняет прокрутку колонок при операции в составе. Проверка источника и подтверждение регистрации выполняются в правой колонке. Поиск чужих листов использует контракт ACS-GM-03A. Для бестиария добавлена фильтрация по имени и ключу. «Недавние» показывает последние регистрации в этой сессии. Портреты берутся из доступных данных персонажей или бестиария. Если изображения нет, карточка использует значок типа.

`modal-gm.css` использует токены ATF для типографики, рамок, отступов, полей и акцентов. Декоративный `gm-forest.webp` создан для этой панели, занимает около 37 КБ и применяется через CSS GM. Тема может предоставить собственный фон через `--af-acs-modal-background`.

## Действия и контракты

- «Проверить готовность» читает существующую серверную проверку на текущей вкладке. «Далее: Проверка» открывает отдельный шаг проверки.
- «Сохранить состав» отправляет открытую форму назначения на сторону. Создание стороны, отношения сторон, регистрация, назначение и запуск используют прежние отдельные команды, разрешения, CSRF и версии. Переходы между вкладками выполняют чтение.
- HP берётся из состояния существа, AP из текущего хода группы через действующий контракт. До появления хода или при недоступном значении AP отображается прочерк. Готовность отмечается после успешной проверки.
- Перестановка и удаление участника при подготовке показаны недоступными. В действующем серверном контракте для них нет команд. Изменение стороны работает через `participant_side`. При постраничном составе счётчики подписаны как значения текущей страницы.
- Коды и пути проверок остаются в раскрываемой диагностике для пользователей с правом аудита. В основном сценарии выводятся причины, требующие действия.

## Загрузка

`ThreadComponents.php` обновляет версии только файлов GM и модального лаунчера. Стили GM запрашиваются при прямом открытии авторизованной панели или внутри её фрагмента. Лаунчер использует действующий шлюз `has_acs_panel`. Изображение запрашивается при применении стилей GM. Новых глобальных подключений, зависимостей и изменений в модалках аккаунтов и уведомлений нет.
