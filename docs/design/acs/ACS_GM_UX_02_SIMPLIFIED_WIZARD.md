# ACS-GM-UX-02 — Мастер подготовки боя

Мастер GM состоит из четырёх шагов. В URL используется `gm_stage`; прежние ссылки с `gm_step` ведут на соответствующий новый шаг.

| Шаг | Действия |
|---|---|
| Настройки | Создать столкновение с названием и сохранить условия завершения |
| Состав | Выбрать и зарегистрировать источник, затем отдельно добавить существо на сторону и настроить отношения сторон |
| Проверка | Прочитать проверку полного сохранённого состава, снимков, прав управления и конфигурации |
| Запуск | Просмотреть состав и отдельно подтвердить запуск первого раунда при положительной проверке |

Создание сессии для темы остаётся отдельным подтверждаемым действием перед настройкой столкновения. Название задаётся при создании, поскольку у существующего сервиса нет отдельной команды переименования. Навигация по шагам использует GET. Проверка на шагах «Проверка» и «Запуск» вызывает существующий серверный read-only маршрут. Команда запуска повторяет проверку.

## Состав и регистрация

Панель источников открывается рядом с составом внутри существующей модалки GM. На узких экранах она располагается над составом и сохраняет собственную прокрутку. Она использует `AF_ACS_EntitiesPage` и существующие источники регистрации. Предпросмотр передаёт ключ операции, который требует маршрут POST в модалке. При успешной проверке мастер показывает отдельное подтверждение регистрации. Ответ остаётся на шаге «Состав» и сохраняет выбранный источник в навигации модалки, пока открыт выбор.

При подтверждённой регистрации мастер закрывает выбор, обновляет список и предлагает добавить новое существо на выбранную сторону. Добавление выполняет отдельную команду `participant_add`. Если стороны ещё нет, мастер предлагает сначала её создать. После обновления страницы зарегистрированное существо доступно в списке для добавления.

Ошибки проверки источника показаны в панели выбора. При неизвестном исходе записи существующий транспорт модалки сохраняет исходный запрос и позволяет повторить его с тем же ключом. Переход на следующий шаг не повторяет команду.

## Расширенные инструменты

Версии, снимки, группы, обязательства, восстановление, засада, журнал и управление действующим боем доступны из раскрываемого раздела «Расширенные настройки и диагностика». Владение листом, разрешения, CSRF, версии, подтверждения и идемпотентность проверяют прежние сервисы.
