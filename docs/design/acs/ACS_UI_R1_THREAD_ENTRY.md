# ACS-UI-R1 — Вход в бой из темы

## Режим темы и доступ

- В явно обычной теме `normal` ACS не выводит кнопку и игровую панель. Прямой запрос `acs_setup=1` также проверяет режим темы. При отсутствии сохранённого режима подтверждённое намерение AdvancedThreadFields служит признаком боевой темы в разрешённом форуме.
- В боевой теме без сессии кнопка «Настроить бой» доступна GM, который имеет серверное право создать сессию в опубликованной теме. Открытие мастера по GET показывает форму. Создание проходит через существующую команду ATF по POST с проверкой CSRF. Если сессия уже создана, повторный вход ведёт к доступной сессии.
- Сессия без столкновения показывает компактный статус подготовки без `thread-panel.js` и общего runtime ACS. GM получает ссылку на настройку. При наличии столкновения панель использует существующую серверную проекцию аудитории.
- В теме с несколькими доступными сессиями панель предлагает выбрать одну. Список и явный выбор ограничены действующими ролями в текущей теме. Для исторической сессии без признака боевого режима можно открыть связанную тему из записи сессии с параметром `acs_panel_session`. Эта ссылка проверяет родную тему и членство. Доступ к инструментам GM дополнительно проверяет роль.

## Композиция

Adaptive Theme Framework выводит действие ACS в верхнем тулбаре рядом с «Новый ответ» через `thread.toolbar_actions`. В R1 ссылка открывает существующий мастер GM или ведёт к панели в текущем документе. У SVG-кнопки есть название и доступная метка. Модальный интерфейс относится к R2.

`thread.before_quick_reply` размещает единственный контейнер ACS непосредственно перед `atf-thread__quick-reply`. На мобильной ширине карточка остаётся в потоке страницы. Фильтры, таймеры и проверка актуальности работают в панели столкновения. Раскрытие использует нативный `details`.

При выкладке запустить штатное обновление Adaptive Theme Framework до 0.32.13, чтобы применить шаблон `showthread` и стили тулбара. В наборах с изменённым вручную шаблоном проверить наличие обеих новых переменных слотов.

### Ручная приёмка на форуме

1. Открыть обычную тему под GM и игроком, включая прямой запрос с `acs_setup=1`. Убедиться, что кнопка, мастер и runtime боевой панели отсутствуют.
2. В боевой теме без сессии открыть мастер под GM и подтвердить создание через форму. Сверить, что GET оставляет тему без сессии, и проверить вход под игроком.
3. В сессии без столкновения проверить статус и действие «Настроить бой» под GM. В активном бою сверить выдачу GM и игроку, а при нескольких сессиях проверить выбор и отклонение чужого ID.
4. Из записи исторической сессии открыть связанную тему. Проверить доступ участника и отклонение ссылки пользователю без роли или с подменённым TID.
5. На десктопе и телефоне проверить порядок панели и редактора, раскрытие и прокрутку, кнопку «Новый ответ», пагинацию и postbit.
