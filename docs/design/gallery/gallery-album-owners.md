# Владельцы на карточках альбомов Advanced Gallery

Под названием альбома в общем шаблоне advancedgallery_album_tile добавлена строка «Автор: Имя пользователя». Имя экранируется и передаётся штатной функции MyBB build_profile_link(). Для удалённого владельца показано «Удалённый пользователь» без ссылки.

Каталог, включая представление модератора, и «Мои альбомы» получают UID/username владельца в существующем запросе списка через LEFT JOIN users по uid_owner. Отдельного запроса пользователя на каждую карточку нет. Существующие запросы обложек и количества изображений не менялись. Других вызовов рендерера карточек в репозитории нет; списки альбомов в Picker и селекторах используют кнопки/option, а не эти карточки.

Прежние условия выбора альбомов, последующая проверка ag_can_view_album(), сортировка, редактирование и удаление сохранены. Модератор видит владельцев доступных ему приватных альбомов; обычным пользователям не добавляется доступ к таким альбомам. Новых полей БД нет.

Используется существующий компактный .ag-meta с overflow-wrap:anywhere. Размеры обложек, сетка и CSS карточек не менялись. Подписи добавлены в языковой manifest с безопасными значениями по умолчанию.

Изменены advancedgallery.php, templates/advancedgallery.html, manifest.php. Добавлена проверка tests/gallery_album_owner_regression.php: реальные рендереры и шаблон, запросы с JOIN, каталог/мои/модератор/гость, приватность, удалённый владелец, экранирование длинных имён, отсутствие отдельных запросов пользователей. Выполнены PHP-синтаксис и короткая регрессия на PHP 8.5, git diff --check. Длительные UI-тесты и установка на сайт не выполнялись.

После установки обновить шаблоны Advanced Gallery штатным механизмом AF, если форум хранит предыдущую версию шаблона в БД.
