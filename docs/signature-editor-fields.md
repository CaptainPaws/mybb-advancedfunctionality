# ASB 1.0.5: поля и AdvancedEditor

Поля заголовка, подзаголовка, статуса, URL изображений и кнопок-ссылок получили явный класс `af-asb__control`. Его стили используют обычные локальные селекторы: тёмно-синий фон, светлый текст, рамка, внутренние отступы и состояния hover/focus. Динамические поля ссылок получают тот же класс. Базовое правило больше не зависит от обработки списка селекторов внутри `:is()` Theme/CSS-парсерами. При этом отсутствие стилей на живой странице здесь не исследовалось через авторизованную сессию.

Основной текст — настоящее видимое поле `signature`, которое существующий AdvancedEditor распознаёт в контексте editsig. ASB не создаёт второй тулбар и не меняет глобальную конфигурацию редактора. Используются его кнопки, зарегистрированные шрифты, ленивая загрузка WYSIWYG, переключение режимов и фильтрация возможностей подписей MyBB. Область редактора занимает доступную ширину строки, переключатель разделителя расположен под ней. При отключении AdvancedEditor остаётся текстовое поле.

Модель получила `text_format: plain|bbcode`. Старые записи по умолчанию остаются plain; при открытии в редакторе буквальные HTML/BBCode старого текста переводятся в безопасные числовые сущности. JSON в базе не меняется от одного открытия. Заголовки/статус остаются простым текстом. Для BBCode-основного текста общий серверный рендерер использует `postParser` MyBB с `allow_html=0`, настройками сигнатур, badword-фильтром и отключённым видео. Нативный переносимый BBCode сохраняет форматирование и экранирует сырой HTML даже при включённом HTML в стандартных подписях. UserDataHandler MyBB по-прежнему проверяет итоговую подпись.

JS слушает штатное событие `af:editor-ready` и `valuechanged` существующего инстанса. Перед черновиком, предпросмотром и отправкой формы он читает актуальное `editor.val()`, а не скрытый устаревший textarea. Повторное событие готовности не добавляет обработчик дважды. Публичные страницы получают только view CSS и существующий файл font-face AdvancedEditor, без его runtime.

Изменены ASB: manifest, template, assets `{af_asb_builder.css,signature-builder.js,signature-view.css}`, modules `{model,usercp,renderer,assets}`. Расширены короткие проверки модели, штатного editor shell и JS-синхронизации. Синтаксис и регрессии проверены; отдельно проверено форматирование/экранирование на исходном парсере MyBB 1.8.40 под PHP 8.5. Визуальная проверка авторизованного warprift.ru не выполнялась. После загрузки файлов обновить ASB через ACP для штатной синхронизации Theme CSS.
