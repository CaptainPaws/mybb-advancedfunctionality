# Targeted Canvas engine checks

Run from the repository root with PHP CLI, Node.js, Playwright and Chromium available:

```sh
php tests/element_theme_effects_regression.php
php tests/element_theme_profile_flow_regression.php
php tests/element_theme_delivery_regression.php
AF_EFFECT_BENCHMARK=/tmp/element-canvas-benchmark.json node tests/element_theme_effects_browser.cjs
```

`PHP_BINARY` and `CHROMIUM_PATH` override the executables. `AF_TEST_BROWSER=firefox`
uses a Playwright-installed Firefox. Optional `AF_EFFECT_SCREENSHOTS` names an
existing directory for six ACP screenshots. No dependency is added to frontend.

The browser test uses local synthetic markup generated by the PHP fixture and
actual surface-owner stylesheets. It verifies profile, external sheet, application,
postbit topbar/sidebar, dynamic sheet insertion/removal and live ACP preview.
Approval/neutral gating is verified by the existing PHP integration fixture.
These checks are not production verification on warprift.ru.

The benchmark measures an isolated profile, isolated sheet, 30 posts / 60 hosts,
and a crowded viewport. It instruments only the engine's actual RAF callbacks
(Playwright's own RAF polling is excluded), observes drawn frames per host,
records bounded scheduler timing samples, checks adaptive tiers, scroll behavior,
cache bounds and repeated DOM cleanup. Reduced motion uses browser emulation;
document inactivity uses a synthetic visibility event and hidden property.
Canvas-unavailable and JavaScript-disabled contexts verify graceful fallback.

Timing covers JavaScript update/draw command submission, not total GPU/compositor
or presentation latency. Heap readings use Chromium CDP garbage collection,
exclude graphics backing stores and describe a short run, not a production soak
or a mobile-device performance guarantee. Hidden bitmaps are released to 1×1;
after all hosts are removed the instance registry and sprite cache must be empty.

## Renderer contracts

`window.afElementCanvasEngine` is the page singleton. `register(host, layer,
config, surface)` is idempotent; `unregister(host)` releases its Canvas and observer
registrations. `refresh(host?)` invalidates geometry/palette, and
`diagnostics()` returns read-only snapshots. A document
`af-element-effects-refresh` event also invalidates live palettes.

One shared IntersectionObserver tracks decorative layers, with one shared
ResizeObserver and one RAF scheduler. Modal clipping ancestors and the viewport
bound the physical bitmap. The engine reads geometry on invalidation, not on
each particle/frame; it never modifies sticky positioning. Palette resolution
uses `--af-element-main/accent/soft/border`, including surface overrides. The
existing optional effect color overrides the particle/accent channel.

Full surfaces target 30 FPS, 40–70 particles, DPR ≤2. Postbits target 24 FPS,
8–16 particles, DPR ≤1.5. Mist/aura allocate fewer particles to atmospheric light.
At 4–8 active hosts density, DPR and FPS decrease; at ≥9 they decrease again.
Sprite textures use a shared 96-entry LRU cache. Feathered turbulence, glow,
stars, embers, crystals and local arcs are generated once per color/type/size;
there are no per-frame gradients or shadowBlur calls.

The current explicit postbit-sidebar host is the moving inner rail, as defined
by upstream ATF. Its Canvas shares that paint plane at z-index 0, above APUI's
image/overlay and below foreground children. The engine does not change the rail
background, sticky offsets, height or scrolling. Legacy outer host attributes
are bridged to that same canonical rail, without creating a second instance.
The browser test checks an opaque author background, foreground controls and
upstream geometry/no-inner-scroll regression contracts.

PHP retains the existing effect metadata/settings. Only the compiled presentation
cache version changes to discard old CSS motion fields. The old CSS keyframes
and gradient-field compiler are removed. ACP preview calls the same singleton
with local unsaved form values and never changes published configuration.
